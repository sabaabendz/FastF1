# Bahrain 2024: model replay versus all classified drivers

## What is compared

The report covers all **20 classified drivers** in the official [FIA final classification](https://api.fia.com/sites/default/files/doc_32_-_2024_bahrain_grand_prix_-_final_race_classification.pdf). For each driver, the project takes that driver's actual lap count, tyre compounds, tyre ages, and pit laps from the OpenF1 data, then estimates the elapsed time for that observed race pattern.

Each replay uses a separate linear regression fitted on eligible laps from the **other 19 drivers**. This leave-one-driver-out method stops the model from fitting directly to the driver's laps it is being evaluated against. The [FIA result table](https://api.fia.com/sites/default/files/doc_32_-_2024_bahrain_grand_prix_-_final_race_classification.pdf) supplies the actual position and elapsed time for comparison.

## Results

Running the comparison on the current Bahrain data gives:

- **20 drivers compared**
- **43.683 seconds mean absolute error (MAE)**
- **53.185 seconds root mean squared error (RMSE)**
- **−12.292 seconds mean signed error** (on average, this replay estimates a faster time)
- Verstappen's actual strategy replay is **+79.948 seconds** slower than his official 1:31:44.742 result.

The dashboard shows all driver errors in a table and plots each prediction against its official time. The diagonal represents a perfect match. The generated report is `reports/bahrain_2024_driver_comparison.csv` (ignored by Git, regenerated by the script).

Recreate the comparison after generating the cleaning audit:

```powershell
python scripts/compare_actual_result.py
```

## How to read the result

This is a **retrospective same-race driver holdout**, not a pre-race forecast. For each row, the model has not seen that driver's laps, but it has seen laps from the other drivers in the same Grand Prix. It can therefore benefit from information about the same circuit, conditions, and race. A genuine pre-race evaluation must train only on previous events and test on an entirely unseen race.

The model predicts tyre-age and compound effects but does not know each car's underlying pace. It uses approximate fuel correction and the same fixed 24.8-second pit-loss proxy. It also does not represent traffic, overtaking, incidents, or safety-car strategy. The comparison is useful because it makes those limitations visible; it does not establish that the current model is race-ready.

Repeating the fit on the same data will not add information. The next useful training step is to load several races, keep each whole race out of training in turn, and compare MAE, RMSE, and bias on those unseen races before adding model complexity.
